# LAB211 Solutions

This folder contains complete Java console solutions for all three supplied assignments:

1. `J1.L.P0028` - Traditional Feast Order Management
2. `J1.L.P0038` - Car Insurance Management
3. `J1.L.P0039` - Student and Short Course Management System

Every project includes:

- full Java source code for every menu function in its PDF;
- input validation and the required file persistence;
- a project-specific `README.md` with build/run commands;
- `DESIGN.md` containing a Mermaid class diagram and program flowchart;
- the original assignment and guidance files.

Run each application from its own project directory so it can locate the supplied data files.

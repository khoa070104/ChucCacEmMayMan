# Car Insurance Management

Complete Java console solution for LAB211 assignment `J1.L.P0038`.

## Build and run

```text
javac -d out src/model/*.java src/data/*.java src/util/*.java src/service/*.java src/app/*.java
java -cp out app.Main
```

The program stores cars in `carInfo.dat` and insurance statements in `insurances.dat`.
Dates use `MM/dd/yyyy`, matching the report format in the assignment.
